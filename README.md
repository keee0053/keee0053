# Eisuke

React Native / Expoを中心に、モバイルアプリを開発しています。
画面を作るだけでなく、Androidネイティブ機能、バックエンド、外部APIとの接続、実機検証まで取り組んでいます。

## Featured Projects

### [SleepyFace](https://github.com/keee0053/sleepy-face)

寝顔写真の撮影とクイズで起床を促す、友達と使う目覚ましアプリ。Android版をGoogle Playで公開しています。

- Expo / React Native / TypeScript / Kotlin
- Supabase / PostgreSQL / Row Level Security
- AlarmManager / ML Kit Face Detection / Push Notifications
- Vitest / ESLint / Prettier / GitHub Actions
- [Google Play](https://play.google.com/store/apps/details?id=com.team5.sleepyface)

### [AIルート](https://github.com/keee0053/ai-route)

Google Mapsのルートと好みを取り込み、AIがルート沿いの寄り道を提案するモバイルアプリ。3名のチーム開発で、モバイルUIとユーザーフローを主に担当しました。

- Expo / React Native / TypeScript
- Cloudflare Workers / Hono
- Google Routes API / Places API / Gemini
- Google Maps共有・URL取り込み / 経由地編集

### [Countdown To-Do List](https://github.com/keee0053/To-Do-List)

期限までの残り時間をリアルタイムに表示するToDoアプリ。Firebase AuthenticationとCloud Firestoreでユーザーごとにタスクを管理します。

- HTML / CSS / JavaScript
- Firebase Authentication / Cloud Firestore / Hosting
- [Live Demo](https://todolist-project-24fb4.web.app/)
